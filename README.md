# Iris Flower Classification Using PyTorch

## Description

Developed a neural network model using PyTorch to classify Iris flowers into three species: Setosa, Versicolor, and Virginica. The project covers data preprocessing, training and testing dataset splitting, neural network architecture design, model training using the Adam optimizer and Cross-Entropy Loss, performance evaluation, and model saving and loading for future predictions.

## Technologies Used
- Python
- PyTorch
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Key Features
- Data preprocessing and label encoding
- Neural network implementation using fully connected layers and ReLU activation
- Model training and loss visualization
- Classification performance evaluation
- Model serialization and inference on new flower samples
